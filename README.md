# Umair — Senior Mobile Developer Portfolio

Modern, high-performance portfolio website for Umair ([umair.dev](https://www.umair.dev)), Senior Mobile Developer specializing in React Native.

## Features
- **Modern Dark Aesthetic**: Subdued dark palette with glassmorphism and metallic accents.
- **Interactive 3D Hero**: Three.js deformed sphere with smooth noise and mouse parallax.
- **Experience Timeline**: Highlighting roles at Hive, AND Digital, and more with active status indicator.
- **Skills Showcase**: React Native, iOS, Android, TypeScript, and state management expertise.
- **Contact Integration**: Pre-filled email inquiries via client-side mailto integration.
- **Automated Deployment**: GitHub Actions workflow directly deploying to Firebase Hosting on merge to `master`.
